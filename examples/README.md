# Example mods

Every one of these is a working mod. Copy a folder into your `mods/`, enable it in
**Options → Mods**, and it runs — no build step, no compiling.

| Example | What it shows |
|---|---|
| [01-hello](01-hello) | The smallest possible mod: changes one number. |
| [02-new-creep](02-new-creep) | Adds a new creep with its own sprite, and spawns it in the first biome. |
| [03-behaviour](03-behaviour) | Creeps that keep their distance or circle you, instead of charging. |
| [04-scripted-verb](04-scripted-verb) | An item whose on-kill effect is written in Lua, with its own name and visuals. |
| [05-boss-fight](05-boss-fight) | Replaces the first boss's fight with one written entirely in config. |
| [06-echo](06-echo) | An artefact that raises the dead — the example for the world query/spawn/state calls. |
| [07-hud](07-hud) | A HUD readout drawn by a mod — the example for the client-side script API. |

They are meant to be read in order: each one adds a single idea to the one before it.

Start with the [guide](../README.md) for the rules, and the [reference](../reference.md) for
the exhaustive key → type → default tables.

## The art in these examples

Every image here is generated by [`tools/make_placeholder_sprites.py`](../tools/make_placeholder_sprites.py)
— plain shapes that exist to prove the pipeline, not to look good. Nothing is taken from the
game, deliberately: the game's own art is licensed to the game and cannot be redistributed, so a
public example has to bring art of its own. **Yours must too** — ship only art and audio you have
the right to distribute.
